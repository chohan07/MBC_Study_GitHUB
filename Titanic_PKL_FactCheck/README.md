
# 🚢 Titanic PKL FactCheck

## 1. 프로젝트 소개

타이타닉 승객 데이터를 PKL 파일로 저장하고,
Python과 Pandas를 활용하여 사실을 검증하는 웹 챗봇입니다.

OpenAI API나 외부 AI 모델 없이 작동하며,
5차 데이터 저널리즘 팩트체킹 평가 실습을 위해 제작했습니다.

## 2. 주요 기능

- PKL 데이터 자동 불러오기
- 타이타닉 승객 156명 데이터 분석
- 사실표 F-1~F-4 자동 생성
- 질문 키워드에 따른 사실 검색
- 근거 기반 답변 및 사실ID 표시
- 근거가 없으면 '확인 불가' 출력
- Streamlit 웹브라우저 화면 제공

## 3. 사용 기술

| 구분 | 기술 |
|---|---|
| 언어 | Python |
| 데이터 분석 | Pandas |
| 데이터 저장 | PKL |
| 질문 처리 | Python 키워드 규칙 |
| 웹 화면 | Streamlit |
| 외부 AI API | 사용하지 않음 |

이 프로그램은 생성형 RAG가 아닌
규칙 기반 팩트체킹 챗봇입니다.

## 5. 주요 분석 결과

| 항목 | 결과 |

### 객실 등급별 생존율

| 객실 등급 | 승객 수 | 생존자 | 생존율 |

## 6. 실행 방법

### 필요한 라이브러리 설치

```powershell
python -m pip install pandas streamlit
```

### 웹앱 실행

```powershell
python -m streamlit run app.py
```

브라우저 접속 주소:

http://localhost:8501

## 8. 프로그램의 한계

- 키워드 기반이므로 질문 표현에 따라 검색 결과가 달라질 수 있습니다.
- 사실표 F-1~F-4 범위 내에서만 답변합니다.
- OpenAI 등 생성형 AI 모델을 사용하지 않습니다.
- 분석 결과는 전체 타이타닉 승객이 아닌 실습 데이터 156명에 한정됩니다.
- PKL 파일은 신뢰할 수 있는 출처에서만 불러와야 합니다.

## 9. 데이터 출처 및 라이선스

- 데이터: 타이타닉 교육용 실습 데이터
- 파일: titanic_data.pkl
- 원본 데이터 출처 및 재배포 조건: 확인 필요
- PKL 파일은 Python 객체 역직렬화 과정에서 보안 위험이 있으므로 신뢰할 수 있는 파일만 사용해야 합니다.
