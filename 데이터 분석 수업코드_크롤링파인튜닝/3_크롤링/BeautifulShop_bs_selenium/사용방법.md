# Beautiful Shop 실습 — 사용 방법 (VS Code)

## 이 폴더에 있는 것
| 파일 | 하는 일 |
|---|---|
| `beautiful_shop.ipynb` | 실습 노트북 — 이것만 열면 돼요 |
| `shop.html` | 연습용 쇼핑몰 (배너 “전 상품 절반 세일!”, 「상품 더보기」 버튼) |
| `login.html` | 연습용 회원 로그인 페이지 (회원가) |

세 파일은 **같은 폴더**에 그대로 두세요. 노트북이 같은 폴더에서 파일을 알아서 찾아요. 경로를 고칠 필요가 없어요.

## 실행 순서
1. VS Code에서 **파일 → 폴더 열기 → `ai-datajournalism-labs`**
2. 왼쪽 탐색기에서 `3_크롤링/BeautifulShop_bs_selenium/beautiful_shop.ipynb` 열기
3. 오른쪽 위 **커널 선택 → Python 환경 → `.venv`**
4. 맨 위 칸부터 차례로 ▶ (Shift+Enter)
   - **준비 확인** 칸에서 ✅ 두 개가 나오면 OK
   - **①** 칸: 결과 마지막 줄 `SALE 2개 / 전체 4개 = 50%`
   - **②·③** 칸은 강사 시연 — 크롬 창이 열리고 버튼·로그인이 저절로 진행돼요

## 막힐 때
| 증상 | 해결 |
|---|---|
| `❌ 없음 → shop.html` | 노트북과 html 파일이 같은 폴더에 있는지 확인 |
| `ModuleNotFoundError: bs4` 또는 `selenium` | VS Code 터미널(.venv 켜진 상태)에서 `pip install beautifulsoup4 selenium` 후 커널 재시작 |
| 커널 목록에 `.venv`가 없음 | README의 「VS Code에서 시작하기」로 가상환경을 먼저 만들기 |
| 크롬 창이 안 뜨고 오류 | 크롬 브라우저가 설치되어 있는지 확인 (드라이버는 Selenium이 자동으로 받아요) |
| 비밀번호 입력칸이 안 보임 | VS Code 창 맨 위 가운데에 입력칸이 떠요 → `beautiful123` 입력 후 Enter |
