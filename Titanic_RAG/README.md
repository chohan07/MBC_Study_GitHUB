
# 🚢 타이타닉 AI 팩트체킹 RAG 챗봇

## 1. 프로젝트 소개

타이타닉 승객 데이터를 분석하고, OpenAI API와 RAG 기술을 활용하여 질문에 근거 기반으로 답변하는 웹 챗봇입니다.

MBC AI 기반 데이터 저널리스트 양성과정의 자동 팩트체킹 실습 프로젝트입니다.

## 2. 주요 기능

- 타이타닉 승객 156명 데이터 분석
- 전체 생존율 및 성별 생존율 계산
- 객실 등급별 승객 수 및 생존율 분석
- 사실표 F-1~F-4 자동 생성
- 질문과 관련된 근거 검색
- OpenAI GPT를 활용한 답변 생성
- 사실ID 표시
- 근거가 없는 질문에는 '확인 불가' 출력
- Streamlit 웹브라우저 인터페이스

## 3. 사용 기술

| 구분 | 기술 |
|---|---|
| 언어 | Python |
| 데이터 분석 | Pandas |
| AI 모델 | OpenAI GPT |
| AI API | OpenAI Responses API |
| RAG 검색 | 키워드 기반 사실 검색 |
| 웹 인터페이스 | Streamlit |
| 데이터 저장 | PKL |

- app.py : Streamlit 웹 챗봇

## 6. RAG 작동 원리

1. 사용자가 질문을 입력합니다.
2. 사실표 F-1~F-4에서 관련 근거를 검색합니다.
3. 검색된 근거를 OpenAI 모델에 전달합니다.
4. AI가 근거에 기반해 답변합니다.
5. 답변에 사실ID를 표시합니다.
6. 근거가 없으면 '확인 불가'를 출력합니다.

현재는 벡터 검색이 아닌 키워드 검색 방식입니다.

## 7. 설치 및 실행 방법

### 라이브러리 설치

```bash
python -m pip install pandas openai python-dotenv streamlit
```

### 데이터 준비

실습 데이터가 담긴 `titanic_data.pkl`을 프로젝트 폴더에 배치합니다.

### OpenAI API 키 설정

`.env` 파일을 만들고 다음 항목을 설정합니다.

```env
OPENAI_API_KEY=본인의_API_키
```

실제 API 키와 PKL 파일은 GitHub에 업로드하지 않습니다.

### 웹앱 실행

```bash
python -m streamlit run app.py
```

브라우저에서 다음 주소로 접속합니다.

http://localhost:8501
